# mri-cognition-eeg-wei2024

**Public.** Code, data and figures accompanying Wei et al. *Sleep* 2024,
*"MRI + EEG predicts cognition (MMSE) jointly better than either alone"*
([doi:10.1093/sleep/zsad294](https://doi.org/10.1093/sleep/zsad294)).
Each notebook reproduces one figure in the paper.

## Layout

```
MRI_PSG_MMSE_Figure 5.ipynb           Figure 5 — MRI+EEG vs each alone (LOO regression)
Figure 3&4/, Figure 5/, Figure 6/     supporting per-figure assets
0510.csv, ALL_bar*.xlsx               cohort tables
```

## Required environment

Python 3 with `scikit-learn`, `numpy`, `pandas`, `scipy`, `matplotlib`.

## Status

Paper archive. Public.
